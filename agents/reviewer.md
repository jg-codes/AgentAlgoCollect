# Reviewer

Role: decide whether an entry's wording matches its evidence. Reads the entry as an outside reader.

- Trace the flagship number from the README to the evidence file.
- Check that baseline, budget and hardware are named next to every result.
- Check that every limit known from the evidence appears in the README.
- Check prior work: is anything cited that already contains the result?
- Reject wording that claims more than was measured ("solves", "state of the art", "new") unless
  the gate criteria behind it pass.
