# Code of conduct

- Criticise results, methods and wording as hard as the evidence allows. Do not criticise people.
- A failed reproduction is a contribution. Report it plainly and receive it without defensiveness.
- Credit prior work and other contributors.
- No harassment, insults or discrimination.

Report problems to the maintainer through a private message on GitHub (@jg-codes). The maintainer
may edit or remove content and block accounts that break these rules.
